# 实验一：线性表

这是任务说明，给学生看的。`course_design.md` 是教案，老师自己用的，不用管。

## 要做什么

把单链表的插入和删除写成一个插件。

课上会看一个示例插件，顺序表的插入删除。作业不是抄它，换成链表自己写一遍，2~3 小时的量。思路是差不多的，但链表底层结构不一样，抄不出来。

## 先把这两件事做完

没跑起来平台的，看 [`getting_started.md`](getting_started.md)。不知道插件怎么写的，看 [`student_manual.md`](student_manual.md)，重点"插件接口"和"新增插件的步骤"两节。

## 看懂示例的结构，别抄代码

打开 `plugins/example_insert/plugin.py`（C 版 `insert_plugin.c`）。

两件事看懂就行：第一行区分算法——输入第一行写 `insert` 或 `delete`，代码先读这行判断走哪个分支，再解析数据，这个写法这次也要用。还有 `run(text, vis)` 就认输入文本、吐一段结果文本，中间怎么写随便。

不用逐行看懂，看懂这个套路，套到链表上。

## 任务

1. 复制 `template/` 到 `plugins/` 下，改个名字，带上学号后四位，比如 `plugins/linklist_1234/`。
2. 实现插入（指定位置插入新节点）和删除（删除指定位置的节点）。
3. 两个算法一个插件，输入第一行区分，跟示例一样。
4. 不用可视化，链表这种指针关系现有三种画法都画不出来，不强求。

## 输入输出格式

格式是定死的，不能自己改——不然助教没法用同一组数据批改。

第一行 `insert` 或 `delete`。

`insert`：第二行原链表的值，逗号分隔，比如 `2,4,6,8,10`，空链表留空；第三行插入位置和值，比如 `0,99`，表示在下标 0（最前面）插 99，位置从 0 数。

`delete`：第二行原链表，第三行要删的位置。

输出不限格式，能看出结果链表从头到尾的值就行，`2,4,100,6,8,10` 或 `[2, 4, 100, 6, 8, 10]` 都行。

这段格式说明抄进 `description` 里。

## 测试数据

自己先跑一遍，助教批改也用这三组：

| # | 操作 | 原链表 | 参数 | 期望结果 | 测什么 |
|---|---|---|---|---|---|
| 1 | insert | `2,4,6,8,10` | 位置 2，值 100 | `2,4,100,6,8,10` | 中间插入 |
| 2 | insert | `1,2,3` | 位置 0，值 99 | `99,1,2,3` | 头插，容易漏掉新节点接管头指针这一步 |
| 3 | delete | `2,4,6,8,10` | 位置 4 | `2,4,6,8` | 删最后一个 |

再测一个：删一个超出范围的位置（比如长度 5 的链表删位置 99），要报错，不能崩或者卡死。这条看行为，不看具体输出文字。

## 怎么算通过

跑得起来、三组数据结果对，就过。代码好不好看、有没有注释、复杂度分析，这次不管。

## 交什么

`plugins/<你的目录名>/` 这一个目录，平台核心文件别带上。
